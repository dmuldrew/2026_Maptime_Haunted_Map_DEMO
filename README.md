# The Haunted Map — European Folklore Behind Halloween Costumes

An interactive Leaflet-powered digital reproduction of a classic gothic poster map exploring the origins and folklore of iconic European Halloween creatures and costumes.

---

## Features

- **Classic Poster & Edge-to-Edge Explorer Modes**: Seamlessly toggle between the authentic Victorian poster layout and an interactive exploration map.
- **Narrated Tour & Eerie Voiceover**: Animated route with synchronized text highlighting and customizable spooky voice synthesis.
- **Atmospheric Gothic Soundscape**: Procedurally generated ambient drone, binaural pulsations, and vintage thunder crackles via the Web Audio API.
- **Interactive Lore Cards**: Draggable folklore cards with high-fidelity vintage illustrations, legends, and location pinpoints.

---

## Deployment to GitHub Pages

This repository is configured for automated static deployment to **GitHub Pages** using GitHub Actions:

1. **GitHub Settings**:
   - Go to your repository on GitHub.
   - Navigate to **Settings** → **Pages**.
   - Under **Build and deployment** → **Source**, select **GitHub Actions**.

2. **Automated Publishing**:
   - Pushing any commit to `main` or `master` will trigger the [deploy workflow](.github/workflows/deploy.yml).
   - You can also manually trigger the workflow at any time under the **Actions** tab using `Run workflow`.
